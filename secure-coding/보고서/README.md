## 핵심 방침

- **보안을 설계 단계부터 반영** (요구사항의 SR → 설계의 구현방식 → 구현 코드 → 테스트 체크리스트로 추적).
- 각 보안 약점은 **Before(취약 코드) → 위험/공격 → After(수정) → 검증** 형식으로 부록에 기록.
- 제출 형식: `[WHS][secure-coding][XX반]이름(전화번호뒷자리).pdf`, 기한 2026-07-24(금) 23:59:59.
